# Руководство по управлению подсветкой MSI Raider 18 (rrgb)

Современная высокопроизводительная утилита и графический интерфейс на 100% чистом **Rust** для синхронного управления поклавишной подсветкой клавиатуры, передней панорамной световой полосой (Lightbar) и логотипом дракона на ноутбуках **MSI Raider 18 HX AI**, **Titan 18 HX** и совместимых игровых платформах.

Все 50 анимаций аппаратно компилируются и загружаются напрямую в контроллеры оборудования (`1038:1122` и `1038:1161`), исполняются встроенными микроконтроллерами, работают с предельной частотой обновления и потребляют **0% CPU** в фоне.

---

## 🚀 Быстрый запуск

### Графический интерфейс (GUI)
Открыть нативный интерфейс на GTK4 и Libadwaita с анимированным предпросмотром, профилями и палитрой:
```bash
rrgb gui
```

### Основные команды CLI
- **Включить подсветку:**
  ```bash
  rrgb on
  ```
- **Выключить всю подсветку:**
  ```bash
  rrgb off
  ```
- **Посмотреть текущий статус и подключенные устройства:**
  ```bash
  rrgb status
  ```
- **Глубокая аппаратная диагностика всех HID-контроллеров:**
  ```bash
  rrgb check
  ```
- **Полный список всех 50 аппаратных пресетов:**
  ```bash
  rrgb effects
  ```
- **Применить сохраненную конфигурацию:**
  ```bash
  rrgb apply
  ```

## 🌈 Каталог 50 уникальных аппаратных режимов

Синтаксис: `rrgb set <РЕЖИМ> [ПАРАМЕТРЫ]`

### 1. Базовые и классические (Core)
- `static` — Статичный ровный цвет на всех клавишах и световом баре:
  ```bash
  rrgb set static -c 00ffff
  ```
- `breathing` — Плавное дыхание выбранного цвета с синусоидальной кривой:
  ```bash
  rrgb set breathing -c ff0055 -s 40
  ```
- `spectrum` — Синхронный циклический перелив всех цветов спектра:
  ```bash
  rrgb set spectrum -s 45
  ```
- `rainbow` — Бегущая плавная радужная волна во всех направлениях:
  ```bash
  rrgb set rainbow -s 50 -d right
  ```
- `wave` — Направленная бегущая волна пользовательского оттенка:
  ```bash
  rrgb set wave -c 00ff88 -s 50 -d out
  ```
- `starlight` — Мерцающее звездное небо (случайные вспышки звезд в глубоком космосе):
  ```bash
  rrgb set starlight -c ffffff -s 40
  ```
- `reactive` — Динамическая реакция на нажатия клавиш с настраиваемым цветом вспышки:
  ```bash
  rrgb set reactive -c 001133 --highlight 00ffff -s 60
  ```

## ⚙️ Параметры и флаги командной строки

| Флаг | Параметр | Диапазон / Значения | Назначение |
| :--- | :--- | :--- | :--- |
| `-c`, `--color` | HEX-код | `ff0000`, `00ffff`, `ffffff` | Основной базовый цвет |
| `--highlight` | HEX-код | `ffffff`, `ff0080` | Цвет вспышки клавиши (для `reactive`) |
| `-b`, `--brightness` | Число | от `0` до `100` (%) | Уровень яркости подсветки |
| `-s`, `--speed` | Число | от `0` до `100` (%) | Скорость аппаратных переходов |
| `-d`, `--direction` | Строка | `right`, `left`, `up`, `down`, `out`, `in` | Пространственный вектор волны |
| `--wave-size` | Число | от `0` до `100` (%) | Длина пространственной волны |

## 🛠️ Особенности реализации
- **Zero Allocations & 0% CPU:** После загрузки кадров в контроллер процесс мгновенно завершается. Сама анимация циклически рассчитывается процессором клавиатуры.
- **Выделенный Hardware Worker:** Графический интерфейс обновляет контроллеры через неблокирующий системный поток с защитой от фризов и дребезга при быстрых переключениях.
- **Поддержка Scroll Lock:** Корректная обработка клавиши `ScrLk` на аппаратном сканкоде `0x47` во всех режимах.
- **Двухзонная раздельная подсветка:** Возможность задавать независимый цвет для фронтального светового бара и логотипа дракона отдельно от клавиатуры.
